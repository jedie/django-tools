# AGENTS.md

This file provides guidance to AI coding agents when working with code in this repository.

## Project

A library of miscellaneous utilities for Django.

* `django_tools/` is the published package
* `django_tools_project/` is the dev/test Django project

## Commands

```bash
./manage.py --help              # See all existing Django manage commands
./manage.py test                # run all tests
./manage.py test <module.path>  # run a single test module
./manage.py coverage            # run tests with coverage
./manage.py code_style          # lint and format
./manage.py nox                 # full CI matrix
```

## Git

Every commit message must include a `Co-Authored-By` trailer identifying the AI agent that helped author it.

## Notes

- `manage.py` is a `uv` bootstrap script can be used like Django's standard manage.py.
- Test settings: `django_tools_project/settings/tests.py` (in-memory SQLite).
- `*.snapshot.*` files are auto-generated by tests — never edit manually.
- `django_tools_project/django_tools_test_app/migrations/` Should only contain the first migration!
  If changes are needed, delete the existing file and recreate it with `./manage.py makemigrations`.
